## Working rules

- The ACL Anthology PDF is the source of record. Study-unit Markdown line
  numbers in the seed are pointers; map every graded claim to a printed page,
  table or figure before freezing the contract.
- Step 0 re-derives the printed-only contradictions, source conventions and
  random-split identities, records prior exposure, and freezes the analysis
  contract before project audit code or cluster-derived estimates. Step 0
  informs the reproduction; it does not replace it.
- Preserve the original stage numbering. The authorized deliverable is the
  released-cluster audit: Wiki-40B, C4, RealNews and the comparison visualizer.
  Substring recounts, EXACTSUBSTR and memorization experiments are deferred.
- Stream the large C4 archive without extracting its full CSV. Do not launch a
  NEARDUP reimplementation: the released clusters, not a new clustering run,
  are the instrument under test.
- Freeze split joins, duplicate-URL handling, cluster-bin edge conventions,
  removal rules, figure targets and kill criteria before opening C4 results.
  Never select whichever convention gives the preferred verdict.
- Keep faithful printed-target audits separate from explanations and sensitivity
  analyses. A negative or partial reproduction is a valid outcome. Use
  "incompatible with the stated procedure; consistent with X", never motive
  language.
- Raw inputs are immutable. Record URL, version or commit, acquisition date,
  bytes, SHA-256 and rights in the raw manifest. Cluster-CSV redistribution
  rights are unresolved; keep downloads local and publish aggregates only.
- Keep each stage's inputs, outputs, verification and report together. Do not
  overwrite a named run. Write text outputs as UTF-8 with LF line endings and
  run Python with `-B`.
- Follow the Charter's three-attempt cap for a consistently failing action.
  Type-A checks cover identity, counts, execution and numerical agreement;
  scientific and reader judgments require independence.
- No Git repository, environment installation, data acquisition or analysis was
  authorized by setup. Publication remains a separate user decision.
